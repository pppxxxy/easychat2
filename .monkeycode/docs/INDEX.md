## 快速参考

### 命令

```bash
npm install          # 安装依赖
npm run start        # 启动 Expo 开发服务器
npm run android      # 在 Android 打开
npm run build:apk    # EAS 预览 APK
npm run prebuild     # 生成原生工程
```

### 重要文件

| 文件 | 目的 |
|------|------|
| `App.js` | 应用入口与导航 |
| `src/ChatScreen.js` | 聊天主流程 |
| `src/storage.js` | 持久化封装 |
| `src/api.js` | 大模型接口调用 |
| `src/context/AppContext.js` | 全局角色状态 |
| `app.json` | Expo 应用配置 |
| `metro.config.js` | 打包配置（package exports 开关） |
