## 2. 需要修正（实施前必须改口径）

### 2.1 v1 的 MAX_DEPTH 例子算错（结论方向对，例子错）

v1 说 `repos/easychat2/main/src/workspace/panel/X.js`（**7 段**）深度 8、会被藏掉。
实测（内存假文件系统，注入 4 个深路径文件）：**只列出 2 个**——被藏的是
`src/i18n/locales/zh-CN/app.js` 与 `a/b/c/d/e/f/g.js`（**≥8 段**，即目录层级 > 6），
`panel/X.js` 实际**可见**。修 MAX_DEPTH 的必要性成立，但验收用例要按 ≥8 段构造。

### 2.2 v1/v2 的行号已漂移（按符号定位，别按行号）

`WorkspacePanel.js` 现 1347 行（v1 写 1351）、`WorkspaceChat.js` 现 1106（写 1103）、
`SettingsScreen.js` 装配段现 L1973-1985（v1 写 L2099-2114——z1007z7 拆过设置页编排层，
文件从 2173 缩到 1996 行）。结构判断全对，但行号不可直接引用。

### 2.3 v4「ShellExecutor 流式输出」不成立（影响 T1 终端设计）

Kotlin 模块**没有任何事件发射**（无 `emit`/`sendEvent`/`DeviceEventEmitter`）：
`StreamPump` 线程只做并发排空与 64KB 上限，`promise.resolve` 在 `waitFor` 结束后
**一次性**返回。所以：

- 能做：命令历史、cwd 面包屑、CTRL+C（`kill` 真强杀）、非交互命令（ls/cat/grep…）。
- 不能做（按现模块）：命令执行中**逐行滚动回显**；长命令期间界面只能转圈。
- 若 T1 要真终端观感，需**新增流式原生模块**（事件发射），不是「零新原生代码」。

### 2.4 v4「Chaquopy 运行时 pip 装包 / 镜像源切换」不成立（影响 T2 设计）

Chaquopy 官方 FAQ 明确：所有包必须在 **build 时**用 `build.gradle` 的 `pip` 块装进 APK；
**没有运行时 pip**。因此 v4 设计的 `pipInstall(packages, mirror)`、`pipList()`、
「设置面板·软件源管理（清华/阿里源）」这一整节**按原样做不了**。

- 能做的：build 时声明依赖 + `PythonBridge.runScript()` 跑脚本 + agent 的 `run_python` 工具。
- 做不了的：用户在设备上装/卸任意包、切镜像源装包。
- 若要保留「装包」体验，需另找方案（打包一批预置 wheel 或自建纯 JS 安装器），成本另估。

### 2.5 v4 的 targetSdk 是 36，不是 35

`app.json` 未显式设 `targetSdkVersion`，走 Expo SDK 54 默认；`node_modules/expo-modules-core`
的 Gradle 插件默认 `compileSdk = targetSdk = 36`。不影响 W^X 结论（≥29 即撞墙），
但文档口径要改。

### 2.6 v4 的 Chaquopy 许可表述宜改

官方页：自 **12.0.1 起 free & open-source、无许可限制**（页面未逐字写 SPDX=MIT）；
最新 17.0 支持 AGP 7.3–9.2。写「MIT」不如写「免费开源（12.0.1+，无许可限制）」稳妥。

### 2.7 补充两条文档没点出的边界

- **目录条目 bug 只在面板侧**：聊天侧 `project.js::extractRepoFiles` 已自带
  `!name.endsWith('/')` 过滤（`project.js:108`），不受此 bug 影响；它另有 400 文件 /
  单文件 512KB 的更紧上限。v1「导入代码没识别目录」只对 `repoImport.js` 成立。
- **v3 的删除红线大部分已完成**：`riskGate.js` 已是白名单 + 硬禁止形态 + 执行层复检，
  不是「默认禁用待升格」；真正缺的只是**守卫断言**（catalog 里出现删除类工具名时报错）。

### 2.8 版本间编号不一致（执行前统一）

v1 的「Stage 6 清场」在 v2 里重编号为 Stage 5；v4 又追加 Stage 7/8。合并后的建议编号：
**0 止血（已完成）→ 1 骨架 → 2 文件面板 → 3a/3b GitHub 面板 → 4 对话+设置面板 →
