# 界面层

界面层负责应用外壳、导航与四个功能页面，是用户可感知的全部交互入口。

## 结构

```
App.js                    # 应用外壳、导航容器与底部标签
src/
├── ChatScreen.js         # 聊天页：消息列表、发送、错误气泡、角色切换、公告、持久化
├── MemoryScreen.js       # 记忆页：历史会话列表、续聊、置顶、克隆、删除
├── SearchScreen.js       # 跨会话搜索：关键词检索历史消息并跳转定位
├── ScrollScrubber.js     # 快速定位滑动条：拖动跳转会话任意位置
├── CharacterScreen.js    # 角色页：角色库列表、编辑、导入角色卡、世界书与正则
├── SettingsScreen.js     # 设置页：API 地址、模型与密钥
├── ImageGenScreen.js     # 生图页：服务与模型选择、提示词、图生图、结果画廊
├── ExtensionScreen.js    # 扩展页：分段切换「游戏」与「生图」，游戏用 WebView 运行内嵌 HTML
├── games/games.js        # 内嵌 HTML 小游戏清单（猜数字、贪吃蛇、打砖块）
└── disclaimer.js         # 免责条款文本与弹窗组件
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `App.js` | 启动垫片、`AppProvider`、`NavigationContainer`、五个 `Tab.Screen`（聊天 / 记忆 / 角色 / 扩展 / 设置），并渲染全局 `Header`；首次启动经 `StartupDisclaimer` 弹出免责条款，`StartupSession` 迁移旧消息并开启新会话 |
| `src/ChatScreen.js` | 聊天主流程；顶部展示当前角色并可经 `Modal` 切换，右上角「公告」重看免责条款，另有「搜索」与「总结」入口；按 `activeSessionId` 读写消息，发送前经 `chatPipeline` 组装消息，展示前经 `regexEngine` 应用正则；含 HTML 的助手消息经 `react-native-render-html` 渲染样式，其余助手消息用 Markdown 渲染；会话内搜索标记命中并支持上一个/下一个定位；切换角色或会话的迟到回复由 `chatRace` 与会话 `id` 共同守卫 |
| `src/MemoryScreen.js` | 记忆页：陈列摘要非空的会话（头像、角色名、摘要与时间），提供续聊、置顶、克隆与删除，克隆会话显示「副本」标识，空列表展示空状态；顶部搜索入口打开 `SearchScreen`；「编辑」模式支持多选与批量删除 |
| `src/SearchScreen.js` | 跨会话搜索：全屏 Modal 输入关键词，经 `storage.searchMessages` 列出命中片段、角色名与时间，点击结果切换角色与会话并设置定位目标 |
| `src/CharacterScreen.js` | 角色库列表（点选切换、新建、删除）与当前角色编辑；保存时用 `buildSystemPrompt` 合成 `systemPromptComposed`；PNG/JSON 角色卡导入；世界书与正则以折叠标题行陈列，点击在 Modal 中逐条编辑与增删；提供「群聊」多选面板创建群聊会话 |
| `src/SettingsScreen.js` | API 多配置管理：列表陈列、点选切换、编辑与增删，带 HTTP 明文确认；预设管理与免责条款入口 |
| `src/disclaimer.js` | 导出 `DISCLAIMER_TEXT` 与可复用 `DisclaimerModal`，供启动弹窗、聊天公告与设置页共用 |
| `src/ImageGenScreen.js` | 生图界面：服务与模型下拉、提示词与尺寸/种子、图生图上传预览、生成加载态与错误提示、结果画廊（点击保存/分享或复制）；「填密钥」打开设置面板填写地址、密钥、模型与额外参数 JSON；支持 `embedded` 属性在内嵌场景隐藏标题 |
| `src/ExtensionScreen.js` | 扩展页：分段控件切换「游戏」与「生图」；游戏区展示名称与说明，选中后用 `react-native-webview` 的 `WebView` 加载内嵌 HTML，顶部返回列表，加载失败展示重试；生图区内联渲染 `ImageGenScreen embedded`；游戏与生图两视图同时挂载，切换用 `pointerEvents` 与透明度控制以保留已填内容；`react-native-webview` 不可用时隐藏游戏入口并提示 |
| `src/games/games.js` | 导出 `GAMES` 与 `getGame`：猜数字、贪吃蛇、打砖块三个纯前端 HTML，字符串内嵌、无网络依赖 |

## 依赖

**本模块依赖**:
- `../src/context/AppContext` - 读取当前角色、角色库、会话列表与更新方法
- `../src/storage` - 消息与配置持久化
- `../src/api` - 发送聊天请求
- `../src/chatPipeline` - 组装含世界书与正则的请求消息
- `../src/regexEngine` - 展示时应用 AI 输出正则
- `../src/cardParser` - 解析 PNG/JSON 角色卡
- `../src/chatRace` - 判断迟到回复是否应被丢弃
- `../src/secrets` - 报错脱敏
- `react-native-markdown-display` - 渲染不含 HTML 的助手 Markdown
- `react-native-render-html` - 渲染含 HTML 标签的助手消息
- `expo-document-picker`、`expo-file-system`、`parsecard` - 角色卡导入
- `expo-clipboard`、`expo-sharing`、`../src/imageGen` - 生图结果复制、保存与生成调用
- `react-native-webview` - 在扩展页运行内嵌 HTML 小游戏
- `../src/disclaimer` - 免责条款文本与弹窗组件
- `@expo/vector-icons` - 顶部品牌徽标与底部标签栏图标

**依赖本模块的**:
- 无（位于依赖树顶层）

## 规范

### 文件命名
- 页面组件：`<Name>Screen.js`，默认导出同名组件
- 页面内私有组件：同文件内以 PascalCase 函数定义

### 代码模式

**页面组件结构**:
```javascript
export default function XxxScreen() {
  const { character, loaded, updateCharacter } = useApp();
  const [state, setState] = useState(initial);
  // 副作用与处理函数
  return (
    <KeyboardAvoidingView ...>
      <ScrollView ...>{/* 内容 */}</ScrollView>
    </KeyboardAvoidingView>
  );
}
```

**异步提交与提示**:
```javascript
try {
  await updateCharacter(next);
  Alert.alert('已保存', '...');
} catch (error) {
  Alert.alert('保存失败', '请检查存储空间或权限。');
}
```

### 样式

- 每个文件底部用 `StyleSheet.create` 定义样式
- 统一暗色板：背景 `#1a1a2e`、输入/卡片 `#2d2d44`、主色 `#6c63ff`、次要文字 `#aaa`
- 禁用态 `opacity: 0.45`

### 错误处理

- 所有展示给用户的错误都通过 `Alert`，写入类异常在界面层捕获
- 聊天报错与角色卡解析报错都必须经 `src/secrets.js` 的 `maskSecrets` 脱敏后才可展示或落盘
- 流式失败且已收到部分文本时，保留该部分回复（标记为完成），并在其后追加系统报错消息
- 主动取消不产生系统报错：`isCanceledError` 为真时保留已收到的部分回复，无文本则移除占位
- 角色卡 PNG 无数据与解析失败给出不同提示，解析失败附带脱敏详情

### 生成控制

- 生成中发送按钮切换为「停止」，点击调用当前请求的 `AbortController.abort()`
- 切换角色或会话与组件卸载时中断进行中的请求，避免后台空耗流量与电量
- 每个请求持有独立的 `AbortController`，`finally` 中清空 `abortRef` 防止误用

### 聊天滚动

- 消息列表在内容增长时（`onContentSizeChange`）自动滚到底部
- 仅当用户处于底部附近（阈值 80px）才执行，用户上滚查看历史时不被流式增量打断
- 发送新消息时强制重置到底部状态并滚动，确保新消息可见

### 免责条款与公告

- 条款文本集中在 `src/disclaimer.js` 的 `DISCLAIMER_TEXT`，所有展示处统一引用，避免多处副本
- 首次启动时由 `App.js` 的 `StartupDisclaimer` 弹出一次，用户确认后写入 `@easychat2_disclaimer_ack`
- 读取确认标记失败时按「未确认」处理，仍弹出条款
- 聊天页右上角「公告」按钮与设置页「免责条款」入口复用同一 `DisclaimerModal`

### 测试

项目当前无自动化测试，界面改动通过 `npm run start` 在真机/模拟器手动验证。

## 添加新页面

1. 在 `src/` 新建 `<Name>Screen.js`，默认导出组件
2. 复用暗色样式常量
3. 在 `App.js` 导入并新增 `<Tab.Screen name="..." component={...} />`
4. 如需全局状态，通过 `useApp()` 获取
5. 用 `npm run start` 验证导航与交互

**检查清单**:
- [ ] 组件默认导出
- [ ] 样式与现有页面一致
- [ ] 已注册到 Tab 导航
- [ ] 存储调用有异常处理
