# 界面层

界面层负责应用外壳、导航与四个功能页面，是用户可感知的全部交互入口。

## 结构

```
App.js                    # 应用外壳、导航容器与底部标签
src/
├── ChatScreen.js         # 聊天页：消息列表、发送、错误气泡、角色切换、公告、持久化
├── MemoryScreen.js       # 记忆页：历史会话列表、续聊、置顶、克隆、删除
├── SearchScreen.js       # 跨会话搜索：关键词检索历史消息并跳转定位
├── ScrollScrubber.js     # 快速定位滑动条：拖动跳转会话任意位置
├── CharacterScreen.js    # 角色页：角色库列表、编辑、导入角色卡、世界书与正则
├── CharacterEditForm.js  # 角色常用字段编辑表单（聊天页就地编辑角色复用）
├── SettingsScreen.js     # 设置页：API 地址、模型与密钥
├── ImageGenScreen.js     # 生图页：服务与模型选择、提示词、图生图、结果画廊
├── ExtensionScreen.js    # 扩展页：分段切换「游戏」与「生图」，游戏用 WebView 运行内嵌 HTML
├── games/games.js        # 内嵌 HTML 小游戏清单（猜数字、贪吃蛇、打砖块、蛇蛇蛇蛇蛇蛇蛇蛇、战机战机战机战机）
├── theme/                # 五套主题、语义色板与字体缩放（ThemeProvider / useTheme），tokens.js 提供间距/圆角/阴影令牌
├── ui/                   # 公共基础组件：Card / Button / Chip / Field / ListRow / SheetHeader（index.js 统一导出）
├── TtsPanel.js           # 语音播报设置面板（播报源与字段表单）
├── MomentsView.js        # 动态时间线（点赞/评论/删除）
├── moments/              # 本地好感启发式与动态触发判定
├── disclaimer.js         # 免责条款文本与弹窗组件
├── GroupEditForm.js      # 群聊信息编辑（名称/头像/背景）
├── speechText.js         # 播报正文清洗（去 Markdown/HTML/状态栏）
├── richHtml.js           # 富 HTML 判定与 WebView 文档包装（围栏剥离、高度桥）
├── RichHtmlMessage.js    # 含 <style>/<script>/<details> 等标签的助手消息用 WebView 渲染（动态高度）
├── cardGreetings.js      # 开场白候选整理与导入决策（纯函数）
├── GreetingPickerModal.js# 导入角色卡时选择/修改/新增开场白
├── ChapterModal.js       # 通用教学弹窗（按章节 id 展示单章或多章）
├── ChapterNotice.js      # 章节章首声明、合规警告与外链（点击前二次确认）
├── ChapterOutro.js       # 章节章末附加块（标题/正文/要点/外链/免责声明）
├── TutorialModal.js      # 使用教程全屏弹窗（ChapterModal 的整篇封装）
├── OnboardingModal.js    # 新手教学分步向导（逐章引导，含图片与进度）
├── onboardingContent.js  # 向导与教程共用章节数据（12 章，厂商/生图清单由预设生成）
├── onboarding/images.js  # 教学截图静态 require 注册表（未注册键返回 null）
└── tutorialContent.js    # 兼容转发：TUTORIAL_SECTIONS = ONBOARDING_CHAPTERS
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `App.js` | 启动垫片、`AppProvider`、`NavigationContainer`、五个 `Tab.Screen`（聊天 / 记忆 / 角色 / 扩展 / 设置），并渲染全局 `Header`；首次启动经 `StartupFlow` 先弹免责条款、再进入新手教学向导，`StartupSession` 迁移旧消息并开启新会话 |
| `src/ChatScreen.js` | 聊天主流程；顶部常驻头像与名称、播报、「新建」与「⋯」更多菜单，菜单收纳公告/模型/思考/定位/搜索/总结/设置；「设置」打开聊天设置弹窗，可进系统设置或就地打开 `CharacterEditForm` 编辑角色（群聊隐藏）；按 `activeSessionId` 读写消息，发送前经 `chatPipeline` 组装消息，展示前经 `regexEngine` 应用正则；含 `<style>`/`<script>` 的助手消息在 `richHtml` 开启时经 `RichHtmlMessage`（WebView）渲染，其余含 HTML 的助手消息经 `react-native-render-html` 渲染，纯文本用 Markdown 渲染；会话内搜索标记命中并支持上一个/下一个定位；切换角色或会话的迟到回复由 `chatRace` 与会话 `id` 共同守卫；左上角角色芯片在群聊会话下仍可点击，切换器同时列出普通角色与群聊会话，选中群聊走 `switchSession` |
| `src/MemoryScreen.js` | 记忆页：陈列全部会话（头像、角色名、摘要与时间），顺序为置顶优先 + 更新时间降序；聚焦时 `refreshSessions` 重读，空 preview 的会话用消息体兜底补摘要，仍为空才显示「（空会话，可删除）」；提供续聊、置顶、克隆与删除，克隆会话显示「副本」标识，空列表展示空状态；顶部搜索入口打开 `SearchScreen`，另有「教学」按钮打开记忆章节；「编辑」模式支持多选与批量删除 |
| `src/SearchScreen.js` | 跨会话搜索：全屏 Modal 输入关键词，经 `storage.searchMessages` 列出命中片段、角色名与时间，点击结果切换角色与会话并设置定位目标 |
| `src/CharacterScreen.js` | 角色库列表（点选切换、新建、删除）与当前角色编辑；保存时用 `buildSystemPrompt` 合成 `systemPromptComposed`；PNG/JSON 角色卡导入时先经 `GreetingPickerModal` 选择/修改/新增开场白再落库，「导入角色卡」下方提供「教学」按钮打开角色卡获取章节；世界书与正则以折叠标题行陈列，点击在 Modal 中逐条编辑与增删；提供「群聊」多选面板创建群聊会话（可选群名，并从已选成员中挑选头像与背景）；角色库网格在非编辑模式下同时展示群聊卡片（群名 + 头像），点击经 `switchSession` 进入对应群聊并跳转聊天页；删除角色时若存在会话会询问是否连同记忆一并删除 |
| `src/CharacterEditForm.js` | 角色常用字段编辑表单（名称、头像、背景、人设、描述、性格、场景、开场白、对话示例、标签），经 `updateCharacter` 保存；供聊天页「编辑角色」复用，世界书与正则在角色页编辑 |
| `src/GroupEditForm.js` | 群聊信息编辑表单（名称、头像、背景），头像/背景可从成员角色卡选择，经 `updateSessionInfo` 保存；供聊天页「编辑群聊」使用 |
| `src/SettingsScreen.js` | API 多配置管理：列表陈列、点选切换、编辑与增删，带 HTTP 明文确认；「新建」先选厂商/协议预设（`apiVendors.js`，含小红书 `api-key` 鉴权），API Key 下方有「点击获取密钥」跳转；API 配置 / 用户人设 / 对话配图 / 向量记忆 卡片各有「教学」按钮打开对应单章；预设管理、使用教程（`TutorialModal`）与免责条款入口 |

## 规范

### 文件命名
- 页面组件：`<Name>Screen.js`，默认导出同名组件
- 页面内私有组件：同文件内以 PascalCase 函数定义

### 代码模式

**页面组件结构**:
```javascript
export default function XxxScreen() {
  const { character, loaded, updateCharacter } = useApp();
  const [state, setState] = useState(initial);
  // 副作用与处理函数
  return (
    <KeyboardAvoidingView ...>
      <ScrollView ...>{/* 内容 */}</ScrollView>
    </KeyboardAvoidingView>
  );
}
```

**异步提交与提示**:
```javascript
try {
  await updateCharacter(next);
  Alert.alert('已保存', '...');
} catch (error) {
  Alert.alert('保存失败', '请检查存储空间或权限。');
}
```

### 样式

- 每个文件底部用 `StyleSheet.create` 定义样式
- 统一暗色板：背景 `#1a1a2e`、输入/卡片 `#2d2d44`、主色 `#6c63ff`、次要文字 `#aaa`
- 禁用态 `opacity: 0.45`

### 错误处理

- 所有展示给用户的错误都通过 `Alert`，写入类异常在界面层捕获
- 聊天报错与角色卡解析报错都必须经 `src/secrets.js` 的 `maskSecrets` 脱敏后才可展示或落盘
- 流式失败且已收到部分文本时，保留该部分回复（标记为完成），并在其后追加系统报错消息
- 主动取消不产生系统报错：`isCanceledError` 为真时保留已收到的部分回复，无文本则移除占位
- 角色卡 PNG 无数据与解析失败给出不同提示，解析失败附带脱敏详情

### 生成控制

- 生成中发送按钮切换为「停止」，点击调用当前请求的 `AbortController.abort()`
- 切换角色或会话与组件卸载时中断进行中的请求，避免后台空耗流量与电量
- 每个请求持有独立的 `AbortController`，`finally` 中清空 `abortRef` 防止误用

### 聊天滚动

- 消息列表在内容增长时（`onContentSizeChange`）自动滚到底部
- 仅当用户处于底部附近（阈值 80px）才执行，用户上滚查看历史时不被流式增量打断
- 发送新消息时强制重置到底部状态并滚动，确保新消息可见

### 免责条款与公告

- 条款文本集中在 `src/disclaimer.js` 的 `DISCLAIMER_TEXT`，分节结构集中在 `DISCLAIMER_SECTIONS`，两者同源；所有展示处统一引用，避免多处副本
- 首次启动时由 `App.js` 的 `StartupFlow` 弹出一次，用户确认后写入 `@easychat2_disclaimer_ack`
- 读取确认标记失败时按「未确认」处理，仍弹出条款
- 聊天页右上角「公告」按钮与设置页「免责条款」入口复用同一 `DisclaimerModal`

### 测试

项目当前无自动化测试，界面改动通过 `npm run start` 在真机/模拟器手动验证。

## 添加新页面

1. 在 `src/` 新建 `<Name>Screen.js`，默认导出组件
2. 复用暗色样式常量
3. 在 `App.js` 导入并新增 `<Tab.Screen name="..." component={...} />`
4. 如需全局状态，通过 `useApp()` 获取
5. 用 `npm run start` 验证导航与交互

**检查清单**:
- [ ] 组件默认导出
- [ ] 样式与现有页面一致
- [ ] 已注册到 Tab 导航
- [ ] 存储调用有异常处理
