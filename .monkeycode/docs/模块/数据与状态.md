# 数据与状态

数据与状态模块负责把角色库、当前角色与消息的持久化细节，以及全局角色库状态从界面中隔离出来。

## 结构

```
src/
├── storage.js            # AsyncStorage 读写封装与默认值
├── context/
│   ├── AppContext.js     # 全局角色库状态与更新逻辑
│   ├── characterLibrary.js # 角色库状态迁移纯函数
│   └── sessionLibrary.js # 会话状态纯函数（排序、摘要、克隆、空会话）
└── polyfills.js          # 运行时 Buffer 垫片（见构建与配置）
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `src/storage.js` | 导出配置/角色库/会话/消息的读写函数与 `DEFAULT_CHARACTER`；处理旧数据迁移 |
| `src/context/AppContext.js` | 暴露 `AppProvider` 与 `useApp()`，提供 `character`、`characters`、`activeId`、`loaded` 等角色状态与操作，以及 `sessions`、`activeSessionId` 与 `switchSession`/`pinSession`/`cloneSession`/`deleteSession`/`refreshSessions` 会话操作 |
| `src/context/characterLibrary.js` | 角色库状态迁移的纯函数：解析当前角色、唯一 id、增删改切换与失败回滚 |
| `src/context/sessionLibrary.js` | 会话纯函数：规范化、排序（置顶优先）、摘要生成、空会话与克隆构造、消息 id 重生成 |

## 依赖

**本模块依赖**:
- `@react-native-async-storage/async-storage` - 设备本机键值存储
- `react` - Context、Hook

**依赖本模块的**:
- `../界面层` - 所有页面通过 `useApp()` 读取角色，通过 `storage` 读写消息与配置
- `../网络层` - `api.js` 读取 API 配置

## 规范

### 文件命名
- 非组件模块使用小写：`storage.js`
- 全局状态放在 `src/context/` 目录

### 代码模式

**容错读取**:
```javascript
async function readJson(key, fallback) {
  try {
    const raw = await AsyncStorage.getItem(key);
    return raw ? JSON.parse(raw) : fallback;
  } catch (error) {
    return fallback;
  }
}
```

**乐观更新加回滚**:
```javascript
const snapshot = { list: charactersRef.current, activeId: activeIdRef.current };
const { list, character } = withUpdatedCharacter(snapshot.list, snapshot.activeId, patch);
applyList(list); // 更新 ref 与 state
await runWithRollback(snapshot, restore, () => saveCharacterLibrary(list));
```
`runWithRollback` 在持久化失败时恢复快照并重新抛出。

会话操作沿用同一模式：`switchSession`、`pinSession` 等先更新 `sessionsRef`/`activeSessionIdRef` 与 state，再调用 `saveSessions`/`setActiveSessionId`，失败时经 `restoreSessions` 回滚并向上抛出。所有写操作经 `mutationRef` 队列串行执行。

### 错误处理

- **读取**：`readJson` 吞掉异常并返回回退值，保证界面始终有可用数据
- **写入**：向上抛出，由界面层决定提示；Context 在抛出前先回滚内存状态
- Context 不弹窗、不依赖任何 UI 组件，只报告失败

### 数据约定

| 键 | 内容 |
|----|------|
| `@easychat2_api_configs` | API 多配置（对象 `{ configs, activeId }`） |
| `@easychat2_api_config` | 旧版 API 单条配置，仅迁移读取，保留不删 |
| `@easychat2_characters` | 角色库（角色数组） |
| `@easychat2_active_character` | 当前角色 `id` |
| `@easychat2_character` | 旧版单角色，仅迁移读取，保留不删 |
| `@easychat2_sessions` | 会话元数据数组 |
| `@easychat2_active_session` | 当前会话 `id` |
| `@easychat2_messages::<sessionId>` | 会话消息（新数据按会话 id 存储） |
| `@easychat2_messages::<characterId>` | 旧版按角色消息，仅迁移读取，保留不删 |
| `@easychat2_messages` | 旧版消息，仅默认角色迁移读取时兜底 |
| `@easychat2_user_profile` | 用户人设（用户名、人设、头像路径） |
| `@easychat2_preset_list` | 全局预设列表（首次读取时由内置预设播种） |
| `@easychat2_global_presets` | 预设开关映射（`{ [presetId]: boolean }`） |
| `@easychat2_memory_summary` | 记忆总结设置（`{ enabled, threshold }`） |
| `@easychat2_plugins` | 插件数组（内置 `web-search`，含 Provider 与密钥等配置） |
| `@easychat2_thinking` | 思考设置（`{ enabled, level, display }`） |
| `@easychat2_image_gen` | 生图设置（`{ activeProvider, providers: { [id]: { apiKey, baseUrl, model, extra } } }`） |
| `@easychat2_chat_options` | 对话选项（`{ streaming, fullWidth }`） |
| `@easychat2_appearance` | 外观设置（`{ themeId, fontScaleId }`） |
| `@easychat2_inline_image` | 对话配图设置（`{ enabled, providerId, stylePrefix, size, maxPromptChars }`） |
| `@easychat2_disclaimer_ack` | 免责条款已读标记（`'true'` 表示已确认） |

### 测试

项目当前无自动化测试。修改后至少手动验证：保存配置、编辑角色、发送消息并重启应用确认数据仍在。

## 添加新持久化数据

1. 在 `src/storage.js` 定义键名与默认值
2. 新增 `getXxx` / `saveXxx`，读取时与默认值合并以兼容旧数据
3. 在界面或 Context 中消费，并处理写入异常
4. 考虑是否需要旧键兜底迁移

**检查清单**:
- [ ] 定义了稳定键名与默认值
- [ ] 读取路径容错并合并默认值
- [ ] 写入路径异常向上抛出
- [ ] 未在持久化数据中写入密钥
