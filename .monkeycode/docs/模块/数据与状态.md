# 数据与状态

数据与状态模块负责把角色与消息的持久化细节、以及全局角色状态从界面中隔离出来。

## 结构

```
src/
├── storage.js            # AsyncStorage 读写封装与默认值
├── context/
│   └── AppContext.js     # 全局角色状态与更新逻辑
└── polyfills.js          # 运行时 Buffer 垫片（见构建与配置）
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `src/storage.js` | 导出配置/角色/消息的读写函数与 `DEFAULT_CHARACTER`；处理旧数据兼容 |
| `src/context/AppContext.js` | 暴露 `AppProvider` 与 `useApp()`，提供 `character`、`loaded`、`updateCharacter` |

## 依赖

**本模块依赖**:
- `@react-native-async-storage/async-storage` - 设备本机键值存储
- `react` - Context、Hook

**依赖本模块的**:
- `../界面层` - 所有页面通过 `useApp()` 读取角色，通过 `storage` 读写消息与配置
- `../网络层` - `api.js` 读取 API 配置

## 规范

### 文件命名
- 非组件模块使用小写：`storage.js`
- 全局状态放在 `src/context/` 目录

### 代码模式

**容错读取**:
```javascript
async function readJson(key, fallback) {
  try {
    const raw = await AsyncStorage.getItem(key);
    return raw ? JSON.parse(raw) : fallback;
  } catch (error) {
    return fallback;
  }
}
```

**乐观更新加回滚**:
```javascript
const old = characterRef.current;
const merged = { ...old, ...patch };
characterRef.current = merged;
setCharacterState(merged);
try {
  await saveCharacter(merged);
} catch (error) {
  characterRef.current = old;
  setCharacterState(old);
  throw error;
}
```

### 错误处理

- **读取**：`readJson` 吞掉异常并返回回退值，保证界面始终有可用数据
- **写入**：向上抛出，由界面层决定提示；Context 在抛出前先回滚内存状态
- Context 不弹窗、不依赖任何 UI 组件，只报告失败

### 数据约定

| 键 | 内容 |
|----|------|
| `@easychat2_api_config` | API 配置 |
| `@easychat2_character` | 当前角色 |
| `@easychat2_messages::<characterId>` | 指定角色消息 |
| `@easychat2_messages` | 旧版消息，仅默认角色兜底读取 |

### 测试

项目当前无自动化测试。修改后至少手动验证：保存配置、编辑角色、发送消息并重启应用确认数据仍在。

## 添加新持久化数据

1. 在 `src/storage.js` 定义键名与默认值
2. 新增 `getXxx` / `saveXxx`，读取时与默认值合并以兼容旧数据
3. 在界面或 Context 中消费，并处理写入异常
4. 考虑是否需要旧键兜底迁移

**检查清单**:
- [ ] 定义了稳定键名与默认值
- [ ] 读取路径容错并合并默认值
- [ ] 写入路径异常向上抛出
- [ ] 未在持久化数据中写入密钥
