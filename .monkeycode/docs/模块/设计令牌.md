# 设计令牌

视觉尺寸的统一来源。新界面与公共组件一律从这里取常量，不再散落内联数值。

**位置**: `src/theme/tokens.js`
**导出**: `tokens`（默认导出同名对象），含 `spacing` / `radius` / `border` / `iconSize` / `opacity` / `metrics` / `elevation(level, theme)`。

## 常量表

| 令牌 | 值 | 用途 |
|------|----|----|
| `spacing.xs / sm / md / lg / xl / xxl` | 4 / 8 / 12 / 16 / 24 / 32 | 内外间距 |
| `radius.sm / md / lg / xl / pill / bubble` | 8 / 12 / 16 / 20 / 999 / 18 | 圆角 |
| `border.hairline / thin / thick` | 0.5 / 1 / 1.5 | 描边宽度 |
| `iconSize.xs / sm / md / lg / xl` | 12 / 14 / 16 / 20 / 24 | 图标尺寸 |
| `opacity.disabled / muted` | 0.45 / 0.7 | 禁用与弱化 |
| `elevation(1/2/3, theme)` | 平台阴影 | 卡片 / 浮层 / 强调浮起 |

## metrics（常用规格）

| 常量 | 值 | 用途 |
|------|----|----|
| `metrics.cardPadding` | 16 | 卡片内边距 |
| `metrics.cardRadius` | 16 | 卡片圆角 |
| `metrics.cardGap` | 12 | 卡片内元素间距 |
| `metrics.buttonHeight` | 44 | 主/次按钮高度 |
| `metrics.buttonRadius` | 12 | 按钮圆角 |
| `metrics.fieldHeight` | 44 | 输入框高度 |
| `metrics.rowMinHeight` | 48 | 列表行最小高度 |
| `metrics.avatarSm / avatarMd` | 34 / 40 | 头像尺寸 |

## 使用约定

- 颜色与字号仍走 `theme.colors` 与 `fonts.scaled`；`tokens` 只管几何尺寸与阴影。
- `elevation` 返回平台相关样式，直接展开进 `StyleSheet` 或 style 数组即可。
- `useTheme()` 返回值里包含 `tokens`，无需单独 import；纯函数/脚本可直接 `import { tokens } from './theme/tokens'`。

## 落地范围

- 公共组件（`src/ui/`）全部以 `tokens` 为几何来源。
- 已 token 化的界面：聊天页（气泡、头像、输入栏、发送键、弹层）、记忆页、动态页、扩展页、生图页、设置页、角色页、两个教学弹窗、免责弹窗。
- 仍保留内联数值的界面：PresetPanel、PluginPanel、TtsPanel、SearchScreen 与 ChatScreen 的少量 Markdown/正则专属样式；新增或改动时优先改用 `tokens`。
