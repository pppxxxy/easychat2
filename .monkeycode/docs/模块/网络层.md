# 网络层

网络层封装与兼容 OpenAI 协议的大模型接口的通信，负责地址归一、请求发送、超时与错误格式化。

## 结构

```
src/
└── api.js                # sendChatMessage 与相关内部函数
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `src/api.js` | 导出 `sendChatMessage`；内部实现 `normalizeChatUrl`、`formatApiError` |

**内部函数**:

| 函数 | 目的 |
|------|------|
| `normalizeChatUrl(baseUrl)` | 将根地址、`/v1` 或完整地址统一为 `/chat/completions` 结尾 |
| `formatApiError(text, status)` | 从 JSON、纯文本或 HTML 响应中提取可读错误 |

## 依赖

**本模块依赖**:
- `./storage` - 通过 `getApiConfig` 读取地址、模型与密钥
- 全局 `fetch`、`AbortController`

**依赖本模块的**:
- `src/ChatScreen.js` - 在发送消息时调用

## 规范

### 代码模式

**带超时的请求**:
```javascript
const controller = new AbortController();
const timeoutId = setTimeout(() => controller.abort(), 30000);
try {
  const response = await fetch(url, { /* ... */, signal: controller.signal });
  // ...
} finally {
  clearTimeout(timeoutId);
}
```

**错误归一**:
```javascript
if (!response.ok) {
  throw new Error(formatApiError(text, response.status));
}
```

### 错误处理

- 未配置密钥时抛出提示，不发起请求
- 超时（`AbortError`）转换为固定中文文案
- 非 2xx 响应优先取后端 `error.message`，HTML 响应退化为 `请求失败（HTTP <status>）`
- 成功但无法解析 JSON 时抛出无法解析错误

### 契约

请求与响应格式参见 [接口文档](../INTERFACES.md#网络接口)。

## 调整请求行为

1. 修改超时时长：调整 `sendChatMessage` 中的 `30000` 毫秒
2. 支持流式响应：需将 `stream` 改为 `true` 并改用流式读取，当前为一次性文本响应
3. 支持额外请求头或参数：在 `fetch` 的 `headers` 与 `body` 中扩展

**检查清单**:
- [ ] 保留了超时清理逻辑
- [ ] 错误信息不包含密钥
- [ ] 更改地址规则后覆盖三种输入形式
- [ ] 手动验证一次成功与一次失败的响应
