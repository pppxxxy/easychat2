# 网络层

网络层封装与兼容 OpenAI 协议的大模型接口的通信，负责地址归一、SSE 流式请求、空闲超时与错误格式化。

## 结构

```
src/
└── api.js                # sendChatMessage、SSE 解析与相关内部函数
```

## 关键文件

| 文件 | 目的 |
|------|------|
| `src/api.js` | 导出 `sendChatMessage`；内部实现 `normalizeChatUrl`、`formatApiError`、`extractDeltaContent`、`extractErrorMessage` |

**内部函数**:

| 函数 | 目的 |
|------|------|
| `normalizeChatUrl(baseUrl)` | 将根地址、`/v1` 或完整地址统一为 `/chat/completions` 结尾 |
| `formatApiError(text, status)` | 从 JSON、纯文本或 HTML 响应中提取可读错误 |
| `extractDeltaContent(payload)` | 从 SSE 事件中取 `choices[0].delta.content`（兼容 `message.content`） |
| `extractErrorMessage(payload)` | 从 SSE `error` 负载中取错误文本 |

## 依赖

**本模块依赖**:
- `./storage` - 通过 `getApiConfig` 读取地址、模型与密钥
- 全局 `XMLHttpRequest`（RN 内置）

**依赖本模块的**:

## 规范

### 代码模式

**基于 XHR 的 SSE 增量读取**:
```javascript
xhr.onprogress = () => {
  const incoming = xhr.responseText.slice(consumed);
  consumed = xhr.responseText.length;
  lineBuffer += incoming;
  const lines = lineBuffer.split('\n');
  lineBuffer = lines.pop() || '';
  lines.forEach(handleLine);
};
```

**空闲超时**:
```javascript
const armIdleTimer = () => {
  if (idleTimer) clearTimeout(idleTimer);
  idleTimer = setTimeout(() => { fail(timeoutError); xhr.abort(); }, 30000);
};
// 每次 onprogress 收到数据后重新 arm
```

**错误归一**:
```javascript
if (xhr.status < 200 || xhr.status >= 300) {
  fail(new Error(formatApiError(xhr.responseText, xhr.status)));
}
```

### 错误处理

- 未配置密钥时抛出提示，不发起请求
- 空闲超时（30 秒无增量）转换为固定中文文案
- 非 2xx 响应优先取后端 `error.message`，HTML 响应退化为 `请求失败（HTTP <status>）`
- SSE 流中出现 `error` 负载时立即抛错并中断
- 服务端忽略 `stream` 而返回整包 JSON 时回退解析 `choices[0].message.content`
- 2xx 但响应既非 SSE 也非可解析 JSON 时抛出无法解析错误
- 收到 `data: [DONE]` 时立即结算并中断，避免服务端保持连接导致空闲超时
- 空响应统一返回 `'没有收到回复。'`

### 契约

请求与响应格式、`onChunk` 语义参见 [接口文档](../INTERFACES.md#网络接口)。

## 调整请求行为

1. 修改空闲超时时长：调整 `sendChatMessage` 中的 `IDLE_TIMEOUT_MS`
2. 支持额外请求头或参数：在 `xhr.setRequestHeader` 与 `xhr.send` 的 body 中扩展
3. 解析更多流式字段：扩展 `extractDeltaContent`
4. 若未来 RN 版本支持 `response.body`，可改回 `fetch` 流式读取，但需同步更新本文档
