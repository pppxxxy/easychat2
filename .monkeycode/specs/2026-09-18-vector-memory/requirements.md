# 需求文档：向量记忆检索

## 简介

为记忆增加向量检索能力：把历史消息切分为片段并生成向量，对话时按相关度召回片段注入请求。向量服务（embedding）地址、密钥与模型在设置页配置；未配置时降级为本地关键词检索。

## 术语表

- **向量检索（Vector Retrieval）**：用语义相似度召回相关记忆片段。
- **嵌入（Embedding）**：把文本转为数值向量。
- **关键词降级（Keyword Fallback）**：未配置向量服务时使用本地关键词匹配。

## 需求

### 需求 1：配置

**用户故事：** 作为用户，我希望配置向量服务，以便启用语义记忆。

#### 验收标准

1. 设置页应提供向量检索开关。
2. 设置页应支持填写接口地址、密钥与模型名。
3. 系统应持久化配置，密钥仅保存在本机。
4. 系统应提供「测试连接」以验证配置可用。

### 需求 2：索引与召回

**用户故事：** 作为用户，我希望对话时自动带上相关记忆，以便角色记住过往。

#### 验收标准

1. 当向量检索开启时，系统应把消息切分为片段并生成向量并保存在本机。
2. 当用户发送消息时，系统应按相关度召回若干片段。
3. 系统应把召回片段作为背景资料注入请求，并标明来源。
4. 系统应限制召回片段数量与总长度。
5. 当片段已存在时，系统应不重复生成向量。

### 需求 3：降级

**用户故事：** 作为用户，我希望未配置时仍可用，以便不因缺服务而失效。

#### 验收标准

1. 当未配置向量服务时，系统应使用关键词检索召回片段。
2. 当向量请求失败时，系统应回退关键词检索且不中断对话。
3. 当索引为空时，系统应不注入记忆片段。
