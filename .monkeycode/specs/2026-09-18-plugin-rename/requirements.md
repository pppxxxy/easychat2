# 需求文档：插件更名为联网搜索

## 简介

把设置页「插件」入口与相关面板文案统一更名为「联网搜索」，保留既有功能与数据。

## 术语表

- **联网搜索（Web Search）**：命中触发词时获取实时资料的插件能力。

## 需求

### 需求 1：文案更名

**用户故事：** 作为用户，我希望入口名称直白，以便理解功能。

#### 验收标准

1. 设置页入口文案应由「插件」改为「联网搜索」。
2. 面板标题与说明文案应统一改为联网搜索表述。
3. 聊天页及其他界面上出现「插件」字样的文案应一律改为「联网搜索」。
4. 更名应不影响既有插件数据与开关状态。
