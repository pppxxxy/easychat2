# 需求文档：角色编辑扩展

## 简介

角色编辑新增备用开场白与对话示例；角色对象统一承载标签、备用开场白与对话示例字段。

## 术语表

- **开场白（First Message）**：新会话建立时的第一条角色消息。
- **备用开场白（Alternate Greeting）**：除主开场白外可选的额外开场白。
- **对话示例（Example Dialogue）**：注入提示词的角色示范对话。

## 需求

### 需求 1：备用开场白

**用户故事：** 作为用户，我希望有多个开场白可选，以便新会话有不同开局。

#### 验收标准

1. 角色编辑应支持添加、编辑与删除多条备用开场白。
2. 当开始新会话时，系统应使用主开场白；当用户选择备用开场白时，系统应使用所选内容。
3. 当角色无备用开场白时，系统应仅展示主开场白。
4. 系统应把备用开场白保存在角色对象内。

### 需求 2：对话示例

**用户故事：** 作为用户，我希望给角色示范对话，以便模型更好地模仿语气。

#### 验收标准

1. 角色编辑应提供「对话示例」多行输入。
2. 当角色存在对话示例时，系统应把示例注入请求的系统提示词。
3. 当对话示例为空时，系统应不注入。
4. 系统应将对话示例保存在角色对象内。

### 需求 4：数据兼容

**用户故事：** 作为用户，我希望旧角色不受影响，以便升级后继续使用。

#### 验收标准

1. 系统应把新增字段作为可选字段保存。
2. 当读取到缺少新字段的旧角色时，系统应正常展示与使用。
3. 系统应在角色卡导出与导入中保留新字段。
