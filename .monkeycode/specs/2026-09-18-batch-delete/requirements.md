# 需求文档：多选批量删除会话

## 简介

记忆页支持进入编辑模式，勾选多个会话后一次删除。

## 术语表

- **会话**：记忆页中一段历史对话。
- **编辑模式**：记忆页中允许勾选会话的状态。
- **全选**：勾选当前可见的全部会话。

## 需求

### 需求 1：进入编辑模式

**用户故事：** 作为用户，我希望一次清理多个历史会话，而不是逐个删除。

#### 验收标准

1. 记忆页顶部应提供「编辑」入口。
2. 当用户点击「编辑」时，系统应进入编辑模式。
3. 编辑模式下，每个会话行应显示勾选框。
4. 系统应提供「全选」与「取消」操作。

### 需求 2：批量删除

#### 验收标准

1. 编辑模式下，用户应能勾选多个会话。
2. 底部应显示「删除（N）」，N 为已勾选数量。
3. 当用户点击「删除」时，系统应弹出二次确认，说明将删除的会话数量。
4. 确认后，系统应删除勾选会话及其消息。
5. 若勾选会话包含当前会话，删除后系统应新建空会话并保持聊天界面可继续使用。
6. 删除完成后，系统应退出编辑模式。

### 需求 3：边界与安全

#### 验收标准

1. 当记忆页没有会话时，系统不应显示「编辑」入口。
2. 当没有任何勾选时，「删除」按钮应禁用。
3. 批量删除失败时，系统应提示错误并保持原会话列表，不产生部分删除。
4. 全选后再次点击全选应取消全部勾选。
