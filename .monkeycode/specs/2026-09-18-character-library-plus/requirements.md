# 需求文档：角色库增强

## 简介

增强角色库：置顶使用星标图标、新增角色搜索（同时匹配角色名与标签）、角色支持标签、多选与全选删除（全选需输入确认）、并把全局预设入口移动到角色编辑区最下方（预设与正则之下）。

## 术语表

- **角色库（Character Library）**：全部角色的集合。
- **置顶（Pin）**：把角色排在列表最前的标记。
- **标签（Tag）**：挂在角色上的关键词，用于检索与分类。
- **多选模式（Selection Mode）**：批量选择角色的编辑态。

## 需求

### 需求 1：置顶图标

**用户故事：** 作为用户，我希望置顶一眼可辨，以便快速识别。

#### 验收标准

1. 系统应使用星形图标表示角色是否置顶。
2. 当角色已置顶时，系统应展示实心星标；未置顶时展示空心星标。
3. 当用户点击星标时，系统应切换该角色的置顶状态并持久化。

### 需求 2：角色搜索

**用户故事：** 作为用户，我希望搜索角色，以便在角色很多时快速定位。

#### 验收标准

1. 角色库应提供搜索输入。
2. 当用户输入关键词时，系统应按角色名匹配并过滤列表。
3. 当用户输入关键词时，系统应同时按角色标签匹配。
4. 当无匹配结果时，系统应展示空状态文案。
5. 当搜索框清空时，系统应恢复完整列表。

### 需求 3：角色标签

**用户故事：** 作为用户，我希望给角色打标签，以便分类与检索。

#### 验收标准

1. 角色编辑应支持添加与删除标签。
2. 系统应把标签保存在角色对象内。
3. 系统应在角色卡片上展示标签。
4. 当标签为空时，系统应不展示标签区域。

### 需求 4：多选与全选删除

**用户故事：** 作为用户，我希望批量删除角色，以便清理角色库。

#### 验收标准

1. 角色库应提供多选模式与全选。
2. 当用户删除多个角色时，系统应二次确认并明确数量。
3. 当用户全选后删除时，系统应展示红色警告并要求输入确认文字。
4. 当删除后仅剩一个角色时，系统应禁止删除并提示至少保留一个。
5. 当删除的是当前角色时，系统应切换到剩余角色并刷新会话。

### 需求 6：角色卡置顶

**用户故事：** 作为用户，我希望在角色卡上直接置顶，以便快速调整顺序。

#### 验收标准

1. 角色卡应同时提供置顶与删除两个操作。
2. 置顶操作应使用星形图标，与列表中的置顶标记一致。
3. 当角色卡已置顶时，系统应展示实心星标；未置顶时展示空心星标。
4. 当用户点击角色卡置顶时，系统应切换该角色的置顶状态并持久化。
5. 置顶状态变化后，角色库排序应即时更新（置顶在前）。

### 需求 5：全局预设位置

**用户故事：** 作为用户，我希望预设入口在角色编辑区底部，以便与角色配置集中。

#### 验收标准

1. 系统应把全局预设入口移动到角色编辑区最下方。
2. 全局预设入口应位于世界书与正则编辑区之后。
3. 当用户打开预设入口时，系统应展示既有预设面板，行为不变。
