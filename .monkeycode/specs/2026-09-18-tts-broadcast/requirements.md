# 需求文档：语音播报（TTS）

## 简介

新增语音播报能力：助手回复完成后可自动朗读回复文本。播报支持安卓系统自带语音引擎与多家云端 TTS 服务（小米 MiMo、硅基流动、讯飞星火、阶跃星辰、腾讯云、阿里云、百度智能云、火山引擎、MiniMax）。云端服务以声明式配置描述，密钥与参数在设置页填写；聊天页顶部栏提供常驻的播报开关。

## 术语表

- **TTS（Text To Speech）**：文本转语音。
- **播报（Broadcast）**：把助手回复文本转换为语音并播放。
- **播报源（TTS Provider）**：一个 TTS 服务，如系统引擎、硅基流动、讯飞星火。
- **系统引擎（System Engine）**：设备操作系统自带的语音合成能力。
- **播报开关（Broadcast Toggle）**：聊天页顶部栏控制是否自动播报的开关。

## 需求

### 需求 1：播报开关

**用户故事：** 作为用户，我希望随时控制助手回复是否自动朗读，以便在安静场合关闭播报。

#### 验收标准

1. 聊天页顶部栏应常驻一个播报开关按钮。
2. 当播报开关开启时，系统应在助手回复完成后自动播报该回复文本。
3. 当播报开关关闭时，系统应停止播报且不自动朗读新回复。
4. 当用户切换播报开关时，系统应持久化开关状态，并在下次启动时恢复。
5. 系统应在播报开关按钮上以视觉状态区分开启与关闭。

### 需求 2：设置入口

**用户故事：** 作为用户，我希望在设置页集中配置播报服务，以便统一管理。

#### 验收标准

1. 设置页应提供「语音播报」横档入口。
2. 当用户点击横档时，系统应展开或打开播报设置面板。
3. 播报设置面板应支持选择播报源、填写该播报源的鉴权字段与参数、选择音色与语速。
4. 系统应内置「系统引擎」与「小米 MiMo」「硅基流动」「讯飞星火」「阶跃星辰」「腾讯云」「阿里云」「百度智能云」「火山引擎」「MiniMax」十个播报源。
5. 系统应将播报源配置保存在本机，不硬编码密钥、不写入文档。

### 需求 3：声明式适配

**用户故事：** 作为用户，我希望只填少量信息就能接入不同厂商，以便按需更换服务。

#### 验收标准

1. 系统应以声明式配置描述各播报源，不为每个服务写死分支。
2. 每个播报源配置应支持：名称、接口地址、请求方法、鉴权方式与字段名、文本字段、音色字段、语速字段、音频返回形式（base64 或二进制或音频地址）与响应解析路径。
3. 当播报源需要先兑换访问令牌时，系统应支持在合成请求前执行令牌兑换并缓存令牌。
4. 当播报源需要请求签名时，系统应支持按播报源声明选择签名方式。
5. 系统应在内置配置不适用时允许用户覆盖接口地址与自定义字段。

### 需求 4：系统引擎播报

**用户故事：** 作为用户，我希望不改动任何配置即可使用手机自带语音，以便快速开始。

#### 验收标准

1. 系统应支持调用安卓设备自带的语音合成能力朗读文本。
2. 当播报源为系统引擎时，系统应支持选择可用语言与语速。
3. 当系统引擎不可用时，系统应给出可读提示且不影响聊天。

### 需求 5：播报控制

**用户故事：** 作为用户，我希望播报可被中断和重播，以便控制收听节奏。

#### 验收标准

1. 当用户发送新消息时，系统应停止正在进行的播报。
2. 当用户点击某条助手消息的播报按钮时，系统应播报该条消息文本。
3. 当播报失败时，系统应给出可读提示且不阻塞后续对话。
4. 系统应对超长回复按长度上限截断后再播报。
