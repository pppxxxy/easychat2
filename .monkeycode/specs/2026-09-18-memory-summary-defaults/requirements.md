# 需求文档：记忆总结默认与阈值修复

## 简介

修复记忆总结阈值修改后无法保存的缺陷；把记忆总结默认状态改为开启。同时规划提示词替换与特殊世界书关键词增强（具体文案等待用户提供，先在设计中预留结构）。

## 术语表

- **记忆总结（Memory Summary）**：把对话压缩成摘要写入角色世界书的机制。
- **触发阈值（Threshold）**：触发自动总结所需的消息条数。

## 需求

### 需求 1：默认开启

**用户故事：** 作为用户，我希望新安装即启用记忆总结，以便自动积累记忆。

#### 验收标准

1. 系统应在未保存过设置时把记忆总结默认设为开启。
2. 系统应保留用户手动关闭的选择，不因升级被强制开启。
3. 系统应使用默认阈值（沿用现有默认值）。

### 需求 2：阈值保存修复

**用户故事：** 作为用户，我希望修改阈值后能生效，以便控制总结频率。

#### 验收标准

1. 当用户修改阈值并离开面板时，系统应保存新阈值。
2. 当用户输入非法值时，系统应回退默认阈值并提示。
3. 当用户输入与当前相同的值时，系统应不重复写入。
4. 当保存失败时，系统应提示并保持原值。

### 需求 3：提示词与关键词（等待内容）

**用户故事：** 作为用户，我希望总结更贴合设定，以便记忆更准确。

#### 验收标准

1. 系统应支持自定义记忆总结提示词（具体文案等待用户提供后填入）。
2. 系统应增强「由记忆总结自动写入的世界书条目」的关键词清单，并提高该类条目的重要性。
3. 系统应不影响用户手动创建的世界书条目的关键词与重要性。
4. 具体关键词清单与重要性数值等待用户提供后填入。
